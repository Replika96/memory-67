## Сохранение

- localStorage сохраняет прогресс на устройстве.
- autosave.js дополнительно пишет выбранный JSON-файл в поддерживаемых браузерах.
- cloud-sync.js обеспечивает вход Google и отправку событий в Firestore.
- sync-state.js объединяет события, изменения карточек и дневную статистику.
- Firestore хранит события в users/{uid}/decks/{deckKey}/events/{eventId}.
- firestore.rules ограничивает доступ uid текущего пользователя.
- В каждом браузере на каждом устройстве нужен вход в один Google-аккаунт.
- Импорт старого сохранения требуется один раз. Сами вопросы приходят с сайта.

## Публикация

- .github/workflows/publish.yml запускается после push в main.
- Ubuntu, Node 22, Firebase CLI 15.35.0, кэш ~/.npm.
- Google Workload Identity Federation, без ключа сервисного аккаунта в репозитории.
- Пул flashcards, провайдер github, аккаунт flashcards-hosting@memory-67.iam.gserviceaccount.com.
- prepare-hosting.ps1 копирует только разрешённые файлы приложения в public.
- CI готовит public через pwsh, убирает Windows predeploy из конфигурации
  только на runner и публикует hosting.
- Workflow публикует Hosting. Правила Firestore через этот workflow не выкладываются.
- При новом push устаревшая публикация отменяется.
- Локально доступны Git и credential manager. Firebase CLI вход на компьютере
  ранее не завершился. Для обычной публикации используй GitHub Actions.
