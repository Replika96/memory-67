# Работа с проектом «Мои карточки»

В начале работы прочитай PROJECT_NOTES.md, проверь git status и последние коммиты.
Другие чаты пользователя работают в этой же папке. Сохраняй их изменения.
Перед публикацией получи свежий main и совмести свои изменения без перезаписи чужих.

После каждого изменения обновляй PROJECT_NOTES.md: что сделано, проверено,
опубликовано и что осталось выяснить. Обновляй число карточек при пополнении.
Указывай даты и различай подтверждённые результаты и предположения.
Не записывай персональные результаты занятий, токены, пароли и учётные данные.

Пользователь разрешил добавлять карточки и публиковать согласованные исправления
через push в main. После публикации дождись GitHub Actions и проверь сайт.
Не объявляй изменение опубликованным только по успешному push.

У карточек стабильные id: старые не менять, новым выдавать уникальные.
Тезисы pts предназначены для самопроверки. В a давай пояснения и примеры,
избегай дословного повторения pts.

Прогресс и файлы экспортов не включать в Git и в публичные файлы сайта.
Подготовка Hosting использует явный список файлов в prepare-hosting.ps1.
